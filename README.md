# TODOLIST

```
todolist/
├── todolist-back/backend   API Fastify + MySQL (porta 3333)
└── todolist-front          Frontend React + Vite (porta 5173)
```

## Backend
```bash
cd todolist-back/backend
npm install
npm run dev
```

## Frontend
```bash
cd todolist-front
npm install
# edite o .env e coloque a URL do backend em VITE_API_URL
npm run dev
```
